# 复习卡片

两种用法，选一种：

## 方式 A：卡片放在笔记里（推荐）

在 `notes/wXX-*.md` 末尾用 `问题::答案` 一行一张，Spaced Repetition 插件会自动收集全 vault 的卡片。

优点：卡片和上下文在一起，忘了可以往上翻。

## 方式 B：集中在这里

按主题建文件：

```
cards/
├── css.md
├── forms.md
└── performance.md
```

每行一张：

```markdown
容器查询和媒体查询的区别？::容器查询看父容器宽度，媒体查询看视口宽度；前者适合可复用组件。
```

## 规则

- 一张卡只问一件事
- 答案是"能背出来的一句话"，不是一段话
- 概念卡用"解决什么问题"提问，不用"是什么"
- 每周日整理：把反复答错的卡片加 `#薄弱` 标签
